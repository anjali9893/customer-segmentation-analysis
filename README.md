# Customer Segmentation Analysis using Python and Power BI

## Project Overview
This project focuses on analyzing retail customer purchasing behavior using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering. The objective is to identify different customer groups and generate meaningful business insights that can support targeted marketing and customer retention strategies.

## Objectives
- Analyze customer purchasing behavior.
- Perform RFM analysis to understand customer value.
- Segment customers based on purchasing patterns.
- Identify high-value, regular, and at-risk customers.
- Visualize customer segments through an interactive Power BI dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- K-Means Clustering
- Power BI

## Project Workflow

1. Data Collection: Work with transactional retail data.
2. Data Cleaning: Prepare and process the dataset.
3. Exploratory Data Analysis: Understand customer purchasing patterns.
4. RFM Analysis: Calculate Recency, Frequency, and Monetary metrics.
5. Customer Segmentation: Apply K-Means clustering to group customers.
6. Dashboard Development: Create an interactive Power BI dashboard to visualize customer segments and metrics.

## Key Activities
- Conducted RFM analysis on transactional retail data.
- Implemented K-Means clustering using Scikit-learn.
- Identified high-value, regular, and at-risk customer groups.
- Designed an interactive Power BI dashboard for customer segmentation insights.

## Business Applications
- Targeted marketing campaigns.
- Customer retention strategies.
- Identification of valuable customer groups.
- Improved customer relationship management.
